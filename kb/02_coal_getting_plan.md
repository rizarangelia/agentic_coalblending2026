# Coal Getting Plan

**Definisi:** Rencana volume & kualitas produksi batubara bulanan per site, disusun oleh Mineplan.

**Proses bisnis:** Per awal bulan (tanggal 3–5), Mineplan mengirimkan plan volume & kualitas coal getting bulanan masing-masing site.

**Atribut per site:** Volume (MT) dan Kualitas CV (kcal/kg GAR).

**Contoh SIMULASI (bukan angka riil):**
| Site | Volume (MT) | CV (GAR) |
|---|---|---|
| Lati | 600.000 | 5.000 |
| Binungan (Binsua) | 1.000.000 | 4.950 |
| Sambarata | 350.000 | 5.900 |
| Gurimbang | 650.000 | 3.880 |
| BMO 3 | 200.000 | 3.350 |
| **Total** | **2.800.000** | |
